# Судейский пульт от клуба pinMode

1. Приятно лежит в руке из-за небольших габаритов
2. Имеет 3 мощных ИК-светодиода для запуска и остановки роботов
3. Имеет 1 ИК-светодиод для установки номера ринга
4. Построен на микроконтроллере Atmega168
5. Позволяет выбирать номер ринга от 0 до 15 
6. Работает от LiPo аккумулятора 
7. Имеет зарядное устройство
8. Заряжается через USB type C
